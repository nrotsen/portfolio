Buen Inventario

The all-in-one back office for small Argentine shops: stock, point of sale, customer credit, ARCA e-invoicing and an online store — built for owners who'd rather not read a manual. El sistema de gestión todo en uno para comercios argentinos: stock, caja, cuentas corrientes, facturación ARCA y tienda online — pensado para dueños que no quieren leer un manual.

HighlightsPuntos clave

  1. Tax invoicing that survives outages. ARCA (AFIP) e-invoicing over SOAP with an emission worker, invoice-number reservation, credit notes, a reconcile cron and certificate-expiry alerts.
  2. Facturación que aguanta caídas. Facturación electrónica ARCA (AFIP) por SOAP con worker de emisión, reserva de numeración, notas de crédito, cron de conciliación y alertas de vencimiento de certificados.
  3. Multi-tenant on DynamoDB, no runtime scans. Every access pattern is a key or GSI query partitioned by company; scans only exist in migration scripts.
  4. Multi-tenant en DynamoDB, sin scans en runtime. Cada access pattern es una query por clave o GSI particionada por empresa; los scans solo existen en scripts de migración.
  5. Payments without double charges. Mercado Pago payments and subscriptions with webhooks deduplicated by payment id.
  6. Pagos sin cobros dobles. Pagos y suscripciones con Mercado Pago, con webhooks deduplicados por payment id.
  7. A counter-ready PWA. Installable admin with barcode scanning (native BarcodeDetector + ZXing WASM fallback), virtualised tables and real-time sync over Socket.io.
  8. Una PWA lista para el mostrador. Panel instalable con lector de códigos de barras (BarcodeDetector nativo + fallback ZXing WASM), tablas virtualizadas y sincronización en tiempo real por Socket.io.
  9. A landing you can use, not just read. The hero is an interactive demo — sell, sell on credit, close the register — prerendered to static HTML; the build fails if the demo didn't render.
  10. Una landing que se usa, no solo se lee. El hero es una demo interactiva — vender, fiar, cerrar caja — prerenderizada a HTML estático; el build falla si la demo no se renderizó.
